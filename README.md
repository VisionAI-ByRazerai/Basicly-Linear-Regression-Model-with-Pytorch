# Student Score Prediction with PyTorch

A beginner-friendly PyTorch project that predicts a student's exam score based on study hours using a simple linear regression model.

## Features

* Built with PyTorch
* Custom `nn.Module` implementation
* Trains using Mean Squared Error (MSE) Loss
* Uses SGD (Stochastic Gradient Descent) optimizer
* Predicts exam scores from study hours
* Displays training and test loss

## Technologies

* Python
* PyTorch
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

## Dataset

The dataset contains:

* **Input:** Study Hours
* **Output:** Exam Score

## How to Run

1. Clone the repository.
2. Install the required libraries.
3. Place `student_performance.csv` in the project folder.
4. Run:

```bash
python train.py
```

## Project Goal

The purpose of this project is to learn the fundamentals of machine learning with PyTorch, including data preprocessing, model training, loss calculation, and prediction.
